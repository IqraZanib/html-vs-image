Verdict. For multilingual lesson plans, code-rendered wins on cost, speed, text correctness, consistency and editability. nano-banana's only edge is generating freehand artwork — and even that is kept here by reusing its illustrations as fixed assets, while the code guarantees correct Urdu/Sindhi text. Recommended path: code-render the page, reuse a library of professional illustrations, and (optionally) let Claude write the per-topic content.
Numbers: render latency measured on this repo (~1.6 s); nano-banana price/latency are published/typical figures; Claude cost estimated from token sizes × Anthropic pricing — see docs/COMPARISON.md for full methodology. No AI image model is used in the code-rendered pipeline.
