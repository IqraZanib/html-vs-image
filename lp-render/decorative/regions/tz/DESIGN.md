# Tanzania design set — government CBC lesson-plan template

**Status: documented, no theme pack yet** — Tanzania renders use the locked default
theme until the partner approves a TZ look. This file is the design-set knowledge to
build that pack from.

**Source of truth:** the Tanzanian government CBC template (via the
curriculum-baked-lesson-plans skill, validated in the Silverleaf review cycle):
- Setup block: Umahiri Mkuu / Umahiri Mahususi · Shughuli Kuu / Mahususi ·
  pupil counts · Zana · Mbinu · Rejea (MUST be dated, e.g. "TET (2023)")
- Lesson body: the 5-column process table — Hatua · Muda · Shughuli za Ufundishaji ·
  Shughuli za Ujifunzaji · Vigezo vya Upimaji — across 4 fixed stages:
  Utangulizi → Kuendeleza Ujenzi wa Umahiri → Kubuni → Tathmini
- Timings must sum to the exact period length (Std 3 ≈ 30 min)

## Binding content rules (from reviewers Aloyce / SLT / Jessica — P1–P23)
Pure Kiswahili chrome (P3/P9) · instructional imperative voice, never past tense (P4) ·
testing criteria in singular, no pupil-count numbers, no AMBER (P5/P13) · pupil action
after every teacher action incl. Kubuni (P6) · dated rejea (P8) · warm-up review +
closing celebration (P14) · multi-sensory beat per activity (P17) · formula before
examples (P18) · orthography check (P19) · preserve: Kona ya Mwalimu, differentiation
(msaada + changamoto), concrete-object hooks, song/chant anchors (P16).

Canonical content example: the «Andalio la Somo — Thamani za Nafasi» template
(place value, Darasa la Tatu — in the design-lane working files / card RES-072).
